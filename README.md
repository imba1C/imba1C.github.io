Официальные ссылки на фреймворк pre-commit:
• Официальный сайт и документация: pre-commit.com
• Официальный репозиторий на GitHub: pre-commit/pre-commit
• Пакет в PyPI (Python): pypi.org/project/pre-commit

Как быстро установить на Windows

Если у вас уже установлен Python, инструмент ставится одной командой:
```powershell
pip install pre-commit
```

После этого в корне вашего Git-репозитория создается файл .pre-commit-config.yaml и выполняется активация хуков:
```powershell
pre-commit install
```
